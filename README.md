# TalentTrade – A Freelance Platform

A Java Full Stack project concept with React frontend and Spring Boot backend.

## Run Frontend
1. Install Node.js.
2. `cd frontend`
3. `npm install`
4. `npm run dev`

## Run Backend
1. Install Java 17+ and Maven.
2. Configure MySQL in `backend/src/main/resources/application.properties`.
3. Create database `talenttrade`.
4. `cd backend`
5. `mvn spring-boot:run`

The frontend currently includes a polished working MVP UI with sample data and local interactions. Backend exposes starter REST APIs for users, services and projects.
